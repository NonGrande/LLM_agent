# Stakeholder Presentation

Канон: `docs/presentation.html` (scroll-snap, тёмная тема GitHub-like).

## Когда трогать

- Крупная веха (релиз, закрытие Tier/Sprint, смена метрик)  
- Явный запрос «обнови презентацию»  
Не после каждого мелкого polish.

## Источник правды (перед правкой)

1. Прочитай `docs/STATUS.md` (версия, тесты, %, Remaining)  
2. Сверь `docs/TZ.md` §5 метрики  
3. Не оставляй устаревшие цифры на титуле/closing (раньше бывало 0.2.0 / 92 теста / Sprint 7 OPEN)

## CSS-параметры (не ломай без нужды)

`:root` в `presentation.html`:

| Токен | Роль | Типичное |
|-------|------|----------|
| `--bg` | фон | `#0d1117` |
| `--bg-card` | карточки | `#161b22` |
| `--border` | границы | `#30363d` |
| `--accent` | синий акцент | `#58a6ff` |
| `--accent2` | зелёный done | `#7ee787` |
| `--accent3` | фиолетовый | `#bc8cff` |
| `--accent4` | оранжевый | `#f0883e` |
| `--danger` | риск | `#f85149` |
| `--text` / `--text-dim` / `--text-mute` | типографика | |

Слайд: `.slide` · `min-height: 100vh` · `scroll-snap-align: start` · padding `60px 80px`.  
Навигация: `.nav-dots` справа — **число точек = число секций** `id="sN"`.

## Обязательный набор слайдов

| # | Назначение | Контент |
|---|------------|---------|
| 1 | Title | Название · 1 subtitle · badges: версия / стек / % |
| 2 | Концепция | что за продукт, 3–4 карточки |
| 3 | Архитектура | Tauri + React + agent (схема/буллеты) |
| 4 | Возможности | **факт текущей версии**, тег `tag-done` |
| 5 | Сравнение | честно vs Cursor/Claude Code — без хвастов |
| 6 | Agentic loop | кратко цикл |
| 7–N | Метрики / roadmap / риски | STATUS Remaining |
| Last | Closing | версия · тесты · ссылки на docs |

Теги: `tag-done` (сделано) · `tag-open` / `.wip` (в работе) — не оставляй OPEN на уже закрытом.

## Closing — обязательные цифры

Обновляй блок `.stats-row` и текст:

- Версия приложения (`0.3.0` и т.д.)  
- Число vitest из STATUS  
- Номер последнего шага journal  
- Следующий фокус = **первая строка Remaining**, не выдуманный спринт  

Ссылки `.docs-links`: STATUS · TZ · PLAN · ARCHITECTURE · progress · USER.

## Новая презентация (другой проект)

1. Скопируй `docs/presentation.html` как шаблон.  
2. Замени тексты; сохрани `:root` и классы `.slide*`.  
3. Синхронизируй nav-dots ↔ секции.  
4. Все % и версии — только из STATUS/TZ этого репо.

## Антипаттерны

- Презентация новее STATUS (или наоборот)  
- «OPEN» на закрытых вехах  
- Завышенный % без IDE-gap  
- Emoji-спам и фиолетовый glow сверх токенов темы
