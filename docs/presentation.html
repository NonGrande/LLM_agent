01 — Концепция

Что такое LLM Shell?

Оболочка для взаимодействия с LLM с полным программным доступом к системе

💬

Чат с LLM

Интерактивный потоковый чат с любой языковой моделью. Streaming-вывод, Markdown, подсветка кода, мультимодальность.

📁

Доступ к файлам

Чтение, запись, редактирование, поиск файлов и директорий. Полный доступ к проекту — как у IDE.

🖥️

Выполнение команд

Запуск shell-команд (PowerShell, bash, zsh). Стриминг вывода, таймауты, управление процессами.

🔄

Автономный агент

Многошаговый цикл: LLM сама решает, какие инструменты вызвать, итеративно решая задачу без участия человека.

04 — Преимущества

Почему LLM Shell

Перед Cursor · Claude Code · Copilot · Aider — честно по факту 0.3.0

1

Свои API и failover

OpenRouter / xAI / Yandex / Ollama без vendor lock. Multi-profile failover и health-светофор ✓/401/402/403 — не одна подписочная модель.

2

Контроль и приватность

Локальный desktop, proxy, ключи у себя, MSI под Windows. Альтернатива подписке: свой endpoint + свой агент.

3

Agent IDE без форка VS Code

Чат + tools + @mentions + Terminal + Ask/Agent/Plan + MCP + multi-LSP. Ориентир ~89–91% agent workflow vs Cursor.

4

Площадки и Combat-профили

Несколько workspace, роли, Success RAG, Pin → AGENTS — ближе к продуктовой оболочке, чем CLI (Claude Code / Aider).

5

Диагностика API

Понятные 401/402/403 и недоступность вместо «просто не работает». Зелёный светофор — быстрый выбор модели.

6

Честный gap

Нет debugger как у Cursor; updater endpoint и Authenticode — ops. Фокус LLM Shell — агент, tooling и контроль стека.
